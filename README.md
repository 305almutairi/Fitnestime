# برنامج الحديد – Technogym

موقع ثابت (HTML) جاهز للرفع على GitHub Pages.

## الملفات
- `index.html`: الموقع كامله.
- `images/`: حط فيه صور التمارين بالأسماء المكتوبة تحت (صيغة JPG).
- `.nojekyll`: يخلي GitHub Pages يخدم الملفات كما هي.

لو الصورة غير موجودة يظهر زر «أضف أو غيّر الصورة» ويشتغل الموقع عادي.

## الرفع على GitHub Pages
1. أنشئ مستودع جديد وارفع محتويات هذا المجلد (index.html و images وبقية الملفات).
2. Settings ثم Pages.
3. Source: Deploy from a branch، الفرع main، المجلد /(root)، ثم Save.
4. بعد دقيقة يطلع لك الرابط.
